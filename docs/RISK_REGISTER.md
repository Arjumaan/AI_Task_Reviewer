# Risk Register & Mitigation Strategy

| Risk ID | Category | Description | Severity | Likelihood | Mitigation Strategy |
| :---: | :---: | :--- | :---: | :---: | :--- |
| **RSK-01** | Hardware | **Host RAM Bottleneck (8 GB Total, ~1 GB Free)**: Loading large models (>3B) or unoptimized memory pools will cause severe swapping or OOM crashes. | High | High | Restrict models to quantized 1B–3B GGUF via Ollama. Use int8 `base.en` Whisper for STT. Ensure single-model residency in memory. |
| **RSK-02** | External Dependency | **Google Meet Bot Detection & Entry Policy**: Google Meet frequently changes UI selectors, displays bot-detection CAPTCHAs, or restricts anonymous guest joining. | High | High | Implement robust selector fallback heuristics; prompt human host for "Admit" approval; provide full **Web Voice Room** local fallback for guaranteed evaluation continuity. |
| **RSK-03** | Audio Pipeline | **Virtual Audio Cable Configuration**: Audio routing between Chromium and Python might experience drift, latency, or device mismatch. | Medium | Medium | Implement automated device query and validation via `sounddevice`; support both DirectSound and MME drivers; provide an Audio Test & Calibration page. |
| **RSK-04** | Ethics / Compliance | **Deceptive AI / Silent Recording**: AI participant could be mistaken for human, or recordings made without informed consent. | Critical | Low | Hardcode AI identification (`"Task Reviewer AI (Assistant)"`); mandate audible disclosure and verbal/button consent before recording or transcription commences. |
| **RSK-05** | Security | **Untrusted Document Ingestion & Prompt Injection**: User uploads (PDF, DOCX) could attempt indirect prompt injection to alter rubrics or force passing grades. | High | Medium | Treat extracted document text strictly as passive data inside delimited schemas; validate all structured extraction outputs deterministically against Pydantic models. |
| **RSK-06** | Google Integration | **Missing or Expired Google OAuth Credentials**: Google Calendar or Gmail API calls fail when unauthenticated or during offline development. | Medium | High | Implement a robust Mock / Dry-Run mode with detailed console logging and clear UI configuration guides so the app functions fully offline. |
| **RSK-07** | Evaluation | **Hallucinated Evaluation Findings**: Local LLM could produce subjective or fabricated evaluation scores without grounding in transcript or artifacts. | Critical | Medium | Mandate deterministic rubric checks; require verbatim transcript quotes or file hash references for every criterion; default to `HUMAN_REVIEW_REQUIRED` when evidence is ambiguous. |
